## Mebahel's Zombie Horde v2.0.1

### Minecraft 1.21.1

## What's New

- Added an in-game configuration menu through Mebahel's API.
- Added a guided horde creator: start from a preset, choose creatures and equipment, select dimensions and biomes, then review your horde before saving.
- Hordes can be named, edited, duplicated and deleted. Searchable creature and item catalogues support content from other mods, without requiring IDs to be typed.
- Advanced editor options let you adjust relative frequencies, equipment chances and item weights.

## Improvements

- Configuration changes are validated and saved server-side by operators. Existing configuration files remain compatible.
- Fixed weapon chances set to 0% being reset when loading configurations.

## Requirements

- Requires Mebahel's API **1.1.5** or newer for Fabric 1.21.1.
